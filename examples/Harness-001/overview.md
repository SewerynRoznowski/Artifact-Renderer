This harness carries both power and the CAN bus between the controller
and the sensor head, in a single shielded bundle.

It exists as a worked example of a manifest: a diagram generated from
source, prose that lives in its own file rather than inside the YAML, and
a section that reaches out to a shared datasheet instead of copying it.

The text you are reading is the artifact's `doc:` - a long-form
introduction, rendered above the sections. It is not a substitute for
`description:`, which is the one line an index listing or a search result
shows.
